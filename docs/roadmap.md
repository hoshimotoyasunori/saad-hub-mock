## 3. P1 — モックで追加予定（今後の開発予定）

優先は状況で入れ替えてよい。追加したら functional / coverage / journey / STATUS も更新。

### 3.1 変更・マスタ

| 予定 | 内容 | 由来 |
| --- | --- | --- |
| R-01 | 契約変更の稟議（受注後の金額・工期）と波及 | journey §5 |
| R-02 | 案件の取引形態・物件の受注後・確認付き変更 | journey |
| R-03 | 外注注文書の版重ね・発行後取消 | journey |
| R-04 | 商品単価・手数料率の改定（適用日） | journey |
| R-05 | 物件・外注・商品・提携先の無効化 | coverage |

### 3.2 取消・請求

| 予定 | 内容 |
| --- | --- |
| R-10 | 請求の赤伝＋再発行 |
| R-11 | 施工後解約＋返金／クーリングオフ |
| R-12 | 承認済みの取消稟議、購買発注後取消依頼 |
| R-13 | 契約白紙、点検対象除外、修理中止、安全「誤報告」 |

### 3.3 一覧・権限・スマホ・帳票

| 予定 | 内容 |
| --- | --- |
| R-20 | 複数選択からの一括CSV／ハガキ送付済 |
| R-21 | 「最近見た」、列表示の本格保存 |
| R-22 | 例外権限申請、人事同期の引き継ぎ自動、管理者強制解除 |
| R-23 | カメラ起票・位置・バーコード・横向き書類・Wi-Fi送信 |
| R-24 | ハガキ一括、実PDF・メール送付（モック深化） |
| R-25 | 通達の版重ね・取り下げ通知 |
| R-26 | 重機レンタル、石綿行政報告、歩合計算ルール（🟡の深化） |
