## 1. プロジェクトの一言

サニックス向け統合基幹 **SAAD** の **UIモック**（静的HTML）。  
旧ASISで散らばっていた「一覧・承認・手配・締め」を、**案件1本のデータ**と **PC台帳／スマホジョブ** の窓で見せ、転記Excelはやめる方針を検証する。

## 3. できていること（要約）

### 3-1. 公開シェル・デバイス

- 1URLで PC／スマホ切替（`index.html`）
- PC: GitHub風台帳（`saad-github-hub.html`）
- スマホ: ジョブ型（`saad-mobile-hub.html`）。旧GitHub Mobileシェルは使わない

### 3-2. 業務モック（幹）

- ポータル・通達・自分宛・通知
- 顧客／物件／商品／外注マスタ、案件台帳・詳細・工程・ゲート・リード・見積
- 稟議・購買・施工・請求・入金・売上・契約事務
- 保証・点検・修理・紹介・取引形態・BI・経費・安全・車両・ナレッジ など（coverage §3 の ✅ 一覧）

### 3-3. 横断の仕組み（優先1〜12）

- 詳細の編集／変更申請／訂正稟議／巻き戻し＋変更履歴
- 担当替え・引き継ぎ待ち、失注・解約の波及
- 代理起票・不在・一括承認・自己承認禁止
- 自動催促・エスカレ、View保存・並び・スコープ
- 入金の赤伝・消込解除、保証再発行／無効、顧客無効化・名寄せ
- 購買カート・送付履歴・帳票モック、スマホのオフライン等、監査ログ・通達既読

### 3-4. PC詳細UX（2026-09-25）

- 詳細は **台帳エリア内の右オーバーレイ**（ページ全体モーダルではない）
- 幅リサイズ（最小〜420px／最大エリアの **2/3**）、外側クリックでは閉じない
- Assignees／右メタは固定幅、進みは日本語（未着手／対応中／完了／準備中）
- Issue親子の一覧⇔詳細の整合（非ツリーViewでも兄弟を文脈行で表示）

## 4. 一部だけ（🟡）

- 重機レンタル、石綿の行政報告、歩合計算ルール
- 添付はファイル名のみ／実PDF・メール未
- 列切替・検索プルダウンは簡易
- 個人情報・手数料の項目別マスク（金額の施工非表示は ✅）
- 見積のスマホ起票

---

## 5. まだ無い（⬜）— 次の塊

| 塊 | 例 |
| --- | --- |
| 変更の残り | 受注後の取引形態変更、単価・手数料の適用日改定、通達の版重ね（契約変更・注文書版重ねは P3 ✅） |
| 取消・無効化の残り | 修理中止・誤報告追記（物件／商品／取引形態無効化・施工後解約／CO・発注後取消・請求赤伝は P3 ✅） |
| 一覧 | 一括CSV／ハガキ、最近見た、列の本格保存 |
| 権限・人事 | 例外権限申請、異動時引き継ぎ自動、管理者強制解除 |
| スマホ・帳票 | カメラ起票・位置・バーコード、ハガキ一括、実PDF送付 |

意図的に作らない（➖）: 勤怠・人事画面・会計仕訳の最終確定（外部SSO／連携）。

P1〜P3 致命抜けの進捗: [hub-asis-critical-impl-plan.md](./hub-asis-critical-impl-plan.md)。
