## 1. モック段階（現在）の受け入れ

| ID | 観点 | 基準 |
| --- | --- | --- |
| AC-M01 | 公開 | PagesルートURLが開ける |
| AC-M02 | 切替 | 幅または `?v=` でPC/スマホが切り替わる |
| AC-M03 | 台帳 | PCで行を開き詳細・タイムラインが見える |
| AC-M04 | 詳細UX | エリア内オーバーレイ・リサイズ・外側クリックで閉じない |
| AC-M05 | スマホ | ホーム→報告または承認の導線を1本完走できる |

| AC-M07 | 文書 | HANDOFF/STATUS/coverage/requirements がリポにある |
| AC-M08 | 親子整合 | 詳細の子が一覧方針と矛盾しない（自分の宿題でも兄弟が見える） |
| AC-M09 | ASIS方針 | 転記Excel再現画面が増えていない |
