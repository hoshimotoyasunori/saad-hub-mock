# 役割別検証シナリオ — 索引（Hubモック通し確認）

> **目的**: ASISに基づき、各役割のシナリオで **新しいシステム（SAAD Hubモック）が通るか** を確認する。  
> **使い方**: 下表のIDを開き、手順どおりにペルソナ切替して操作。結果列に ✅／❌／🟡 を記入。  
> **判定**: `✅通る` `🟡薄い（ここまで）` `➖基幹外（SSO等）` `⛔やらない（転記等）` `⬜未導入`  
> **正本リンク**: [role-verification-scenarios.md](../role-verification-scenarios.md)（役割仕事一覧）／[asis-capability-coverage.md](../asis-capability-coverage.md)／[hub-asis-flow-gap-audit.md](../hub-asis-flow-gap-audit.md)  
> **確認URL**: http://localhost:8123/mocks/saad-github-hub.html?pc=1  
> **作成日**: 2026-09-26

---

## 0. 実施ルール

1. **1シナリオ＝1結果**。通しの途中で止まっても、止まった手順番号を記録する。  
2. **✅以外は失敗ではない**。🟡➖⛔⬜は仕様どおりなら「仕様どおり確認OK」。  
3. 経理・総務・人事・相談室は Hub に専任ペルソナが無い → **近似ロール**で実施（各ファイル冒頭参照）。  
4. 根拠のないシナリオは足さない。必ず ASIS業務ID／成果物／仮分類のどれかを付ける。
