# SAAD 用語集

| 項目 | 内容 |
| --- | --- |
| 文書ID | SAAD-GLOSS-001 |
| 版 | 0.1 |
| 作成日 | 2026-09-25 |
| **性質** | **生きた文書**。用語が増えたら追記 |

| 用語 | 意味 |
| --- | --- |
| SAAD | 新統合基幹（本プロジェクト） |
| ASIS | 旧来の業務・Excel・WF等の総称（現状業務の根拠） |
| Hubモック | 本リポの静的HTMLデモ |
| 案件 / Issue | 台帳の1行。仕事の単位 |
| ゲート | 施工前など、子（稟議・購買）が揃うまで先を止める行 |
| Open / Close | 案件が生きているか。進み（Status）とは別 |
| 進み | 未着手／対応中／完了／準備中 等 |
| View | 同じ表の保存フィルタ（別ページではない） |
| リポ / アプリ | 実体の道具（sfa, ringi, buy…）。台帳は窓 |
| 自分宛 | 自分が止めている宿題・承認 |
| 変更申請 | 確認者の確定まで旧値を残す変更 |
| 訂正稟議 | 承認済み・計上済み等を直すための稟議 |
| スコープ | self/branch/region/division/all のデータ見える範囲 |
| 文脈行 | フィルタ外だが階層理解のために薄い表示で残す行 |
| 型A〜K | ASISで一覧が要った理由の分類（coverage §1） |
