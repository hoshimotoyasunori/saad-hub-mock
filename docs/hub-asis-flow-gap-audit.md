## 2. ユーザー質問への直答

| 問い | 答え |
| --- | --- |
| 営業が契約に至る流れは画面で管理できるか | **一部のみ**。リード〜見積入口はあるが、管理部登録・活動語彙・見積の技術/外注関与・契約書WFが欠ける |
| 営業はいつ・どう管理部へ報告するか | ASISは **依頼時メール／見積申請／受注時LINE WORKS画像／（技術の予定報告）**。Hubは転記廃止と一緒に**報告・確認キューを消している** |
| 契約までの書類 | 依頼書・調査報告・見積（＋外注/材料）・＜30万契約書（WF後）／≥30万工事申込書・署名済証憑・（条件）石綿・契約稟議添付。Hubは**ラベルとモック閲覧**中心 |
| 必要な承認 | 見積（値引・差益・保証）／契約書作成依頼（所属長）／契約稟議（法務・経理分岐）／下請。Hubは**汎用稟議1種に潰している** |
| 管理部（事業系）は何を管理するか | 登録・振分・見積受付・受注確認・契約書発行・お客様確認電話・未調査フォロー・施工予定集約等。Hubの「管理部」は**高額二次承認＋請求**に寄り、**ES管理部事務が欠落** |
| 施工はいつ情報をキャッチし何を準備するか | ASISは**受注／契約時点**で予定組→管理部報告。Hubは契約完了→未割当＋ゲート後。**下請・石綿・締結の前段が抜けたまま** |
