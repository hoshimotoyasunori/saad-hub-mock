## 1. デバイス方針

| 窓 | 方針 | 実装 |
| --- | --- | --- |
| PC | GitHub Issues風の**台帳**。一覧・管理・承認 | `saad-github-hub.html` |
| スマホ | **ジョブ型**（今日やること・報告・承認）。Issue語彙を主UIに出さない | `saad-mobile-hub.html` |
| 切替 | 幅820px／`?v=pc|mobile|auto` | `index.html` |

GitHub Mobileの移植は採用しない。

---

## 2. PC詳細パネル（確定要件）

| ID | 要件 | 状態 |
| --- | --- | --- |
| UI-P01 | 詳細は**台帳エリア内**の右オーバーレイ（ページ全体モーダルではない） | ✅ |
| UI-P02 | テーブル幅は開閉で崩さない | ✅ |
| UI-P03 | 本文｜メタの2カラム。メタ（Assignees等）は固定幅 | ✅ |
| UI-P04 | 左端ドラッグで幅変更。最小〜420px、最大エリアの**2/3** | ✅ |
| UI-P05 | 外側クリックでは閉じない。×／Escape | ✅ |
| UI-P06 | Assignees列（台帳）も固定幅 | ✅ |
| UI-P07 | 進み表示は日本語（未着手／対応中／完了／準備中 等） | ✅ |
| UI-P08 | 一覧と詳細の子Issue集合が矛盾しない | ✅ |

## 5. 用語の約束

| 約束 | 意味 |
| --- | --- |
| Open ≠ 進み | Openは生きているだけ。進みはStatus |
| 仕事は行 | 新しい仕事＝行を足す |
| 台帳は窓 | 実体はリポ／アプリ |
