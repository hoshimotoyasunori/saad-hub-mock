## 3. 実装方針（モック）

1. **データ**: キュー配列（`INTAKE_Q` / `ORDER_Q`）＋既存 `issues` に WF 行。案件に `actStatus` / `orderStatus` / `contractWfId`。
2. **画面**: 台帳・登録の MGMT キュー＋案件パネルCTA＋ヘッダ「＋」。新規ロールは開発用ペルソナ切替。
3. **転記**: Excel3種は作らない。振分・確認は **キュー操作** で代替。
4. **デモ導線**: seed で「登録待ちの依頼」と「確認待ちの受注」を1件ずつ置き、ポータル今日の予定から開く。
